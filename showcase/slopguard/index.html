What the tool doesاین ابزار چه کار می‌کند؟

01

Cross-check dependenciesبررسی نام وابستگی‌ها

Review suspect names against local manifests and the curated package corpus. A similar name is a signal, not a verdict.نام مشکوک را با فایل وابستگی و فهرست بسته‌ها مقایسه کن. شباهت نام سرنخ است، نه حکم قطعی.

02

Inspect code without running itبررسی کد بدون اجرا

The Python scanner works on syntax trees and checks supported imports or symbols; the suite also checks JavaScript imports.پویش پایتون با درخت نحوی و بررسی نام‌ها و importهای پشتیبانی‌شده انجام می‌شود؛ تست‌ها ورودی جاوااسکریپت را هم پوشش می‌دهند.

03

Start with staged changesشروع با تغییرات آمادهٔ کامیت

Scan newly staged lines for pre-commit review. Registry lookup is optional, not part of the offline path.برای بازبینی پیش از کامیت، خطوط تازهٔ آمادهٔ ثبت را بررسی کن. جست‌وجوی رجیستری اختیاری است و در مسیر آفلاین انجام نمی‌شود.

Evidence deskمیز شواهد

Review a fictional staged changeبازبینی یک تغییر فرضیِ آمادهٔ کامیت

  1. Dependency · Manifestوابستگی · فایل وابستگی

    An imaginary generated change adds an unknown package name. The staged review flags it. Compare the lockfile and the original project docs before choosing whether to add anything.یک تغییر فرضی تولیدشده نام بسته‌ای ناشناخته اضافه می‌کند. بازبینی آن را علامت می‌زند. قبل از افزودن چیزی، فایل قفل و مستندات اصلی را مقایسه کن.

  2. Symbol · Installed versionنام · نسخهٔ نصب‌شده

    A referenced symbol is absent from the local version. Check the documented public API and distinguish a genuinely missing symbol from one exposed dynamically.نام ارجاع‌شده در نسخهٔ محلی نیست. رابط عمومی مستندشده را بررسی کن و نام واقعاً غایب را از نامی که پویا ارائه می‌شود جدا کن.

  3. Flag · Versioned helpگزینه · راهنمای نسخه

    The generated option does not appear in the example tool version’s help. Verify against the local help and correct the design without adopting the unknown option.گزینهٔ تولیدشده در راهنمای نسخهٔ فرضی نیست. با راهنمای نسخهٔ محلی تطبیق بده و بدون استفاده از گزینهٔ ناشناخته اصلاح کن.

THE ACTUAL TOOLابزار واقعی

What happens outside the browser?بیرون از مرورگر چه اتفاقی می‌افتد؟

Use the offline path to evaluate supported Python and JavaScript imports, Python symbol references, and known CLI options. A staged-only scan is narrower than a full directory scan. The checked snippet is not run; findings still need a human review. Optional registry lookup asks an external registry and is not required for ordinary offline use.مسیر آفلاین، import پشتیبانی‌شده در پایتون و جاوااسکریپت، نام‌های پایتون و گزینه‌های شناخته‌شدهٔ ابزارها را بررسی می‌کند. بررسی فقط تغییرات آمادهٔ ثبت محدودتر از پوشهٔ کامل است. قطعه‌کد اجرا نمی‌شود؛ هشدار همچنان بررسی انسانی می‌خواهد. مراجعه به رجیستری خارجی اختیاری است و برای استفادهٔ آفلاین لازم نیست.

FIELD NOTESنکته‌های کاربردی

Questions and limitsپرسش‌ها و محدودیت‌ها

Does a flag mean a dependency is malicious?آیا هشدار یعنی بسته مخرب است؟

No. It can mean a likely typo, an unknown package or a mismatch with the local environment. Confirm provenance and necessity separately.نه. شاید نام اشتباه، ناشناخته یا ناسازگار با محیط محلی باشد. منشأ و ضرورت بسته را جداگانه تأیید کن.

Why did a known option get flagged?چرا گزینهٔ شناخته‌شده هشدار گرفت؟

A tool may add or remove options between versions. Check the exact installed version and its help before treating the report as final.گزینه‌ها بین نسخه‌ها عوض می‌شوند. قبل از قطعی دانستن گزارش، نسخهٔ نصب‌شده و راهنمای همان نسخه را ببین.

Does it replace CI or static review?جای CI یا بررسی ایستا را می‌گیرد؟

No. It catches a specific class of generated-code mistakes. Keep dependency review, tests, and language-specific checks in place.نه. دسته‌ای مشخص از خطاهای کد تولیدشده را پیدا می‌کند. بازبینی وابستگی، تست و بررسی ویژهٔ زبان را نگه دار.
