02 / INSTRUCTION AUDIT۰۲ / بازبینی دستورها

skilltrace

A local static auditor for coding-agent instructions. Find conflicting rules and review context size before the instructions reach a model.بازرس ایستای محلی برای دستورهای ایجنت‌های کدنویسی. تعارض دستورها و اندازهٔ متن زمینه را پیش از ارسال به مدل بررسی کنید.

Quick startشروع سریعGitHubگیت‌هاب

What it doesچه کار می‌کند؟

01

Find conflicting rulesپیدا کردن قوانین متناقض

Review instructions across CLAUDE.md, AGENTS.md, GEMINI.md, Cursor rules and SKILL.md.دستورهای فایل‌های CLAUDE.md، AGENTS.md، GEMINI.md، قوانین Cursor و SKILL.md را بررسی کنید.

02

Audit locallyبازبینی محلی

Surface possible secrets and risky permission instructions for manual review. Check whether findings are real before acting.نشانه‌های احتمالی افشای اطلاعات و دستورهای پرخطر را برای بررسی انسانی پیدا کنید. نتیجه را پیش از اقدام بررسی کنید.

03

Set a context budgetبودجهٔ متن زمینه

Review estimated token usage. Add a strict local or CI check when the team agrees on its limit.برآورد مصرف توکن را ببینید و پس از توافق تیم، حد را در بررسی محلی یا CI اعمال کنید.

Quick startشروع سریع

Node.js 18 or later, with no runtime dependencies. Use an authorized local checkout, and do not publish findings that contain sensitive text.نود ۱۸ یا جدیدتر، بدون وابستگی زمان اجرا. مخزن محلی مجاز را بررسی کنید و گزارش حاوی متن حساس را منتشر نکنید.

npm i -g github:mrzroot/skilltrace
skilltrace scan . --max-tokens 6000 --strict --json
skilltrace budget .
