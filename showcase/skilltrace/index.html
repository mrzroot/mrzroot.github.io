02 / TRIAGE

From scan to decisionاز اسکن تا تصمیم

  1. Discover: the scanner reads known rule files, including common CLAUDE.md, AGENTS.md, GEMINI.md and SKILL.md files, plus Cursor and Copilot rule paths.کشف: ابزار فایل‌های شناخته‌شده مثل CLAUDE.md، AGENTS.md، GEMINI.md و SKILL.md و مسیرهای قوانین Cursor و Copilot را می‌خواند.
  2. Inspect: read the finding code and affected file(s), then check the actual project rule. Findings may be false positives.بررسی: کد یافته و فایل مربوط را ببینید، بعد قانون واقعی پروژه را بررسی کنید. گزارش ممکن است مثبت کاذب داشته باشد.
  3. Resolve: align the authoritative instruction, revise only your local checkout, and rescan. The browser queue above is a fictional rehearsal, not the scanner.رفع: دستور مرجع را هماهنگ کنید، فقط نسخهٔ محلی خودتان را تغییر دهید و دوباره اسکن کنید. صف بالای این صفحه فقط تمرین ساختگی است، نه ابزار اسکن.

03 / CI GATE

Choose what should block a buildتعیین کنید چه چیزی ساخت را متوقف کند

A normal scan exits 1 on error-level findings. With --strict, any finding can make the command exit 1. Store a sanitized report when it is useful; keep the raw report out of a public job log.اسکن معمولی روی یافتهٔ سطح خطا با کد ۱ خارج می‌شود. با ‎--strict هر یافته‌ای می‌تواند کد خروج ۱ بدهد. اگر لازم است گزارش پاک‌سازی‌شده نگه دارید و خروجی خام را در لاگ عمومی نگذارید.

skilltrace scan . --max-tokens 6000 --strict --json

04 / BOUNDARIES

A local heuristic, not an enforcement layerبررسی تقریبی محلی، نه کنترل اجباری

Token estimateبرآورد توکن

The code estimates roughly one token per four characters, rounded up, with at least one per file. It is not a model tokenizer.کد تقریباً برای هر چهار نویسه یک توکن در نظر می‌گیرد و رو به بالا گرد می‌کند، با حداقل یک توکن برای هر فایل. توکنایزر مدل نیست.

Bounded discoveryکشف محدود

The scan skips .git and node_modules and limits directory depth. A clean scan does not prove that all files or instructions are safe.اسکن از ‎.git و node_modules می‌گذرد و عمق پیمایش را محدود می‌کند. نبود یافته تضمین نمی‌کند تمام فایل‌ها یا دستورها ایمن‌اند.

05 / FAQ

What a finding meansمعنای گزارش چیست؟

Does the tool change files or permissions?ابزار فایل یا دسترسی را تغییر می‌دهد؟

No. This CLI reads instruction files and returns a report. Review edits separately.نه. ابزار فایل‌های دستور را می‌خواند و گزارش می‌دهد. تغییرات را جداگانه بررسی کنید.

How should I handle possible sensitive text?با متن احتمالاً حساس چه کنم؟

Work in an authorized local checkout. Share a sanitized description, not the raw text; a suspected exposed key should be checked with its owner.در مخزن محلی مجاز کار کنید. شرح پاک‌سازی‌شده را به‌جای متن خام به اشتراک بگذارید و کلید مشکوک را با مالک آن بررسی کنید.

Quick startشروع سریع

Node.js 18 or later, with no runtime dependencies. Use an authorized local checkout, and do not publish findings that contain sensitive text.نود ۱۸ یا جدیدتر، بدون وابستگی زمان اجرا. مخزن محلی مجاز را بررسی کنید و گزارش حاوی متن حساس را منتشر نکنید.

npm i -g github:mrzroot/skilltrace
skilltrace scan . --max-tokens 6000 --strict --json
skilltrace budget .
