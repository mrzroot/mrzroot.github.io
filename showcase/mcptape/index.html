What the tool doesاین ابزار چه کار می‌کند؟

01

Record a sessionضبط نشست

Captures JSON-RPC traffic in NDJSON or Content-Length framing.ترافیک JSON-RPC را با قالب NDJSON یا Content-Length ضبط می‌کند.

02

Replay without the upstreamبازپخش بدون سرویس اصلی

Replay recorded exchanges offline. Seeded error and latency simulation are intended for resilient CI tests.تبادل ضبط‌شده را آفلاین بازپخش می‌کند. شبیه‌سازی تکرارپذیر خطا و تأخیر برای آزمون پایداری CI است.

03

Review compatibilityبررسی سازگاری

Removed tools, new required inputs, and changed parameter types can fail a compatibility check.حذف ابزار، اجباری‌شدن ورودی و تغییر نوع پارامتر می‌تواند بررسی سازگاری را ناموفق کند.

Cassette lifecycleچرخهٔ عمر کاست

A small release rehearsalتمرین انتشار یک ابزار کوچک

  1. 01 · Capture۰۱ · ضبط

    An imaginary team records one catalogue lookup against its own test MCP server. It prepares a small cassette with a known request and result, excluding tokens and private records.یک تیم خیالی، جست‌وجوی فهرست را روی سرور آزمایشی خودش ضبط می‌کند. درخواست و نتیجهٔ شناخته‌شده را بدون توکن و رکورد خصوصی در کاست کوچک نگه می‌دارد.

  2. 02 · Replay۰۲ · بازپخش

    The integration test replays the same fixture before every build. This tests the client against recorded behavior without paying for or waiting on the original upstream.تست یکپارچه‌سازی قبل از هر ساخت همان نمونه را بازپخش می‌کند. رفتار کلاینت را بر اساس نمونهٔ ضبط‌شده و بدون هزینه یا انتظار سرویس اصلی می‌سنجد.

  3. 03 · Compare۰۳ · مقایسه

    The next schema makes language required. The diff flags the change as breaking; the team keeps it optional or updates the client before release.در طرح‌وارهٔ بعد زبان اجباری می‌شود. مقایسه تغییر را ناسازگار می‌داند؛ تیم آن را اختیاری نگه می‌دارد یا قبل از انتشار کلاینت را به‌روز می‌کند.

THE ACTUAL TOOLابزار واقعی

What happens outside the browser?بیرون از مرورگر چه اتفاقی می‌افتد؟

Record follows actual JSON-RPC messages, including newline-delimited or Content-Length framing. Replay presents the captured responses over stdio. Diff focuses on compatibility of tools/list, not all possible behaviors of a server.ضبط، پیام‌های واقعی JSON-RPC را در قالب خط‌به‌خط یا Content-Length پیگیری می‌کند. بازپخش پاسخ ضبط‌شده را روی stdio می‌دهد. مقایسه بر سازگاری tools/list تمرکز دارد، نه همهٔ رفتارهای ممکن سرور.

LOCAL USEاستفادهٔ محلی

Install and try itنصب و اجرای اولیه

Node.js 18+ · from a local cloneNode.js 18 به بالا · از نسخهٔ محلی

node bin/mcptape.mjs --help
mcptape inspect fixtures/example.tape.jsonl --json
mcptape diff fixtures/v1.tape.jsonl fixtures/v2.tape.jsonl --json

If you have not installed the executable, use node bin/mcptape.mjs in place of mcptape. Replace fixture paths with your own sanitized local samples. The CLI returns 1 for breaking schema changes, not for a successful compatible comparison.اگر برنامهٔ اجرایی را نصب نکردی، به‌جای mcptape از node bin/mcptape.mjs استفاده کن. مسیرها را با نمونه‌های محلی پاک‌سازی‌شدهٔ خودت عوض کن. ابزار برای تغییر ناسازگار کد ۱ می‌دهد، نه برای مقایسهٔ سازگار.

FIELD NOTESنکته‌های کاربردی

Questions and limitsپرسش‌ها و محدودیت‌ها

Why does live behavior differ?چرا رفتار زنده فرق دارد؟

Replay covers what was captured, not every server reply. Refresh the fixture intentionally when the accepted upstream behavior changes.بازپخش فقط موارد ضبط‌شده را پوشش می‌دهد، نه همهٔ پاسخ‌ها. اگر رفتار مورد انتظار سرویس عوض شد، کاست را آگاهانه تازه کن.

Should I commit the tape?کاست را کامیت کنم؟

Only after treating its contents like any other recording: review request and reply data, remove secrets/internal records, and keep the smallest useful fixture.مثل هر ضبط دیگری، اول درخواست و پاسخ را بازبینی کن، اسرار و رکورد داخلی را حذف کن و کم‌حجم‌ترین نمونهٔ مفید را نگه دار.

Where does fault simulation help?شبیه‌سازی خطا کجا مفید است؟

Use predictable error or latency samples to check whether a local client handles failures cleanly. It does not replace integration and staging checks.با نمونهٔ تکرارپذیر خطا یا تأخیر ببین کلاینت محلی با خطا درست کنار می‌آید یا نه. این جای تست یکپارچه‌سازی و پیش‌انتشار نیست.
