01 / LANGUAGE QUALITY۰۱ / کیفیت متن

parsieval

An offline evaluator for Persian and bilingual AI outputs: half-spaces, character variants, bidirectional controls and digit consistency.ارزیاب آفلاین خروجی فارسی و دوزبانهٔ هوش مصنوعی؛ برای بررسی نیم‌فاصله، نویسه‌های عربی، کنترل‌های جهت متن و یکدستی اعداد.

Quick startشروع سریعGitHubگیت‌هاب

What it doesچه کار می‌کند؟

01

Persian typographyنگارش فارسی

Check expected half-spaces and flag Arabic variants such as ي and ك in Persian text.نیم‌فاصله‌های مورد انتظار و نویسه‌هایی مانند ي و ك عربی را در متن فارسی بررسی کنید.

02

Bidirectional textمتن دوجهته

Detect bidirectional control characters and mixed numeral sets in the same output.نویسه‌های کنترلی جهت متن و ترکیب مجموعه‌های مختلف اعداد را پیدا کنید.

03

Compare candidatesمقایسهٔ خروجی‌ها

Score or compare local files, optionally using strict checks and JSON output. This does not judge factual accuracy.فایل‌های محلی را امتیازدهی یا مقایسه کنید؛ حالت سخت‌گیرانه و خروجی JSON هم دارد. صحت اطلاعات را نمی‌سنجد.

Quick startشروع سریع

Python 3.9 or newer. The package has no runtime dependencies.پایتون ۳٫۹ یا جدیدتر. بسته وابستگی زمان اجرا ندارد.

pip install git+https://github.com/mrzroot/parsieval
parsieval score output.txt --strict --json
parsieval compare model_a.txt model_b.txt --json
