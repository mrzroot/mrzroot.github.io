01 / LANGUAGE QUALITY۰۱ / کیفیت متن

parsieval

An offline evaluator for Persian and bilingual AI outputs: half-spaces, character variants, bidirectional controls and digit consistency.ارزیاب آفلاین خروجی فارسی و دوزبانهٔ هوش مصنوعی؛ برای بررسی نیم‌فاصله، نویسه‌های عربی، کنترل‌های جهت متن و یکدستی اعداد.

What it doesچه کار می‌کند؟

01

Persian typographyنگارش فارسی

Check expected half-spaces and flag Arabic variants such as ي and ك in Persian text.نیم‌فاصله‌های مورد انتظار و نویسه‌هایی مانند ي و ك عربی را در متن فارسی بررسی کنید.

02

Bidirectional textمتن دوجهته

Detect bidirectional control characters and mixed numeral sets in the same output.نویسه‌های کنترلی جهت متن و ترکیب مجموعه‌های مختلف اعداد را پیدا کنید.

03

Compare candidatesمقایسهٔ خروجی‌ها

Score or compare local files, optionally using strict checks and JSON output. This does not judge factual accuracy.فایل‌های محلی را امتیازدهی یا مقایسه کنید؛ حالت سخت‌گیرانه و خروجی JSON هم دارد. صحت اطلاعات را نمی‌سنجد.

02 / MARGINS

Read the annotations, not just the numberحاشیه‌ها را بخوانید، نه فقط امتیاز

Character signalنشانهٔ نویسه

The issue report includes code, severity and count, with a short sample when available. Keep the original text nearby so a reviewer can see context.گزارش شناسهٔ ایراد، شدت و تعداد را نشان می‌دهد و اگر نمونه داشته باشد آن را می‌آورد. متن اصلی را برای بررسی بافت نگه دارید.

Format is optionalقالب اختیاری است

Use --expect-json only when the response is supposed to be standalone JSON. Valid JSON is syntax validation, not a schema check.فقط وقتی انتظار JSON مستقل دارید از ‎--expect-json استفاده کنید. معتبر بودن JSON یعنی قالب درست است، نه تطابق با شِما.

03 / WORKFLOW

Make it reproducibleمقایسه را تکرارپذیر کنید

  1. Save the exact outputs as UTF-8 A.txt and B.txt. Keep their model, prompt and generation settings with the experiment.خروجی‌ها را بدون دستکاری در فایل‌های UTF-8 به نام A.txt و B.txt ذخیره کنید و تنظیمات مدل و پرامپت را کنارشان نگه دارید.
  2. Run compare and read the two findings lists. Check the marked locations before accepting a format change.مقایسه را اجرا کنید و فهرست ایرادهای هر دو را بخوانید. قبل از پذیرش اصلاح، محل هر نشانه را بررسی کنید.
  3. For a format gate, use score with --strict and a threshold that your team chose from a representative sample.برای کنترل خودکار قالب، از score با ‎--strict و آستانه‌ای که تیم از نمونه‌های نماینده انتخاب کرده استفاده کنید.
parsieval compare A.txt B.txt --json
parsieval score B.txt --strict --min-score 85 --json

04 / LIMITS

Where review still mattersکجا بازبینی انسانی لازم است؟

Typography signals are useful in prose, but quoted Arabic, code and mixed-language references may be intentional. Decide what counts as a failure for the actual audience. Human review still checks meaning, claims and tone.نشانه‌های نگارشی برای نثر مفیدند، اما نقل‌قول عربی، کد و ارجاع دوزبانه ممکن است عمدی باشند. معیار خطا را با توجه به مخاطب تعیین کنید؛ معنا، ادعا و لحن همچنان نیاز به بررسی انسانی دارند.

05 / FAQ

Common questionsپرسش‌های رایج

Does it translate or rewrite?ابزار متن را ترجمه یا بازنویسی می‌کند؟

No. It inspects text and reports findings; the interactive proof desk contains hand-written examples.نه. متن را بررسی و ایرادها را گزارش می‌کند. برگه‌های تعاملی نمونه‌های از پیش نوشته‌شده‌اند.

When does strict mode exit with 1?حالت سخت‌گیرانه چه زمانی کد خروج ۱ می‌دهد؟

For score, when the score is below --min-score or any finding has error severity. The default threshold is 80.در دستور score، اگر امتیاز زیر ‎--min-score باشد یا خطایی با شدت error وجود داشته باشد. آستانهٔ پیش‌فرض ۸۰ است.
