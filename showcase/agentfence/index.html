What the tool doesاین ابزار چه کار می‌کند؟

01

Decide at the boundaryبررسی قبل از اقدام

Local rules can evaluate shell, Git, and SQL action text. The preview is a gate, not a replacement for OS isolation.قواعد محلی می‌توانند متن عملیات شل، گیت و SQL را بسنجند. این دروازه جای جداسازی در سطح سیستم‌عامل را نمی‌گیرد.

02

Estimate the effectپیش‌بینی اثر

Dry run simulates likely filesystem scope without touching disk; it does not prove every side effect is known.اجرای آزمایشی دامنهٔ احتمالی اثر روی فایل‌ها را بدون نوشتن روی دیسک پیش‌بینی می‌کند؛ تضمین نمی‌کند همهٔ اثرها شناخته شده‌اند.

03

Verify the ledgerبررسی دفتر رویداد

Hash chaining makes ledger edits detectable; keep a trusted copy or anchor if someone could replace the entire log.زنجیرهٔ هش دستکاری دفتر را آشکار می‌کند. اگر ممکن است کل فایل جایگزین شود، یک نسخه یا مرجع قابل اعتماد نگه دار.
