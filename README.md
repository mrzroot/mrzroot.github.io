# mrzroot.github.io

Published build of the personal site of **Mohammadreza Zare (M-R-Z / [@mrzroot](https://github.com/mrzroot))**, a Python developer focused on automation, backend and open source.

**Live:** https://mrzroot.github.io/

This repository contains the compiled output that GitHub Pages serves. The editable source is maintained privately; changes to the site should be made in that source and rebuilt, not patched into the published assets.

## Preview an existing build locally

From the repository root, run `python3 -m http.server 8000` and open `http://localhost:8000/`. This only previews the checked-in build; it does not compile or publish it. Stop the server with Ctrl+C.
