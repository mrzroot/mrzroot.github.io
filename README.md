# mrzroot.github.io

Personal portfolio of **Mohammadreza Zare (M-R-Z / [@mrzroot](https://github.com/mrzroot))**, a Python developer focused on automation, backend and open source.

**Live:** https://mrzroot.github.io/

- Static HTML, CSS and vanilla JavaScript. No build step, no dependencies.
- English and Persian (RTL) with a language toggle (`?lang=fa` also works).
- Project stats load live from the public GitHub API, with static fallbacks.
- Accessible: semantic markup, keyboard focus states, `prefers-reduced-motion` support.
- Self-hosted fonts (Inter, JetBrains Mono, Vazirmatn) and no third-party requests on the critical path.
- After editing any asset, run `python3 scripts/stamp-assets.py` to refresh the `?v=` cache-busting hashes.
