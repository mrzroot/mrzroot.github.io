a shared notebook for your team's AI helpersیک دفترچهٔ مشترک برای دستیارهای هوش مصنوعیِ تیم · v0.1.2

گنجینهganjineh

Your team's AI helpers finally share one notebook.دستیارهای هوش مصنوعیِ تیمتان بالاخره یک دفترچهٔ مشترک دارند.

When one person's AI finishes a job, ganjineh writes a short note about it in a notebook your whole team shares. The next person's AI reads that note first, so it does not start from zero.وقتی هوش مصنوعیِ یک نفر کارش را تمام می‌کند، گنجینه یادداشت کوتاهی از آن در دفترچه‌ای می‌نویسد که کل تیم شریک است. هوش مصنوعیِ نفر بعدی اول همان یادداشت را می‌خواند و از صفر شروع نمی‌کند.

Think of a whiteboard in a shared kitchen: whoever cooks leaves a note, so nobody cooks the same dish twice.مثل تختهٔ آشپزخانهٔ مشترک: هر کس آشپزی کند یک یادداشت می‌گذارد تا هیچ‌کس یک غذا را دوبار نپزد.

Example: Alice's AI builds the login button. Later, Bob's AI is asked for the login part of the server. It finds Alice's note and reuses her plan instead of inventing a new one. No server, no account, no extra AI calls.مثال: هوش مصنوعیِ آلیس دکمهٔ ورود را می‌سازد. بعد از هوش مصنوعیِ باب بخش ورودِ سرور خواسته می‌شود. او یادداشت آلیس را پیدا می‌کند و به‌جای ساختن یک طرح تازه، از همان استفاده می‌کند. بدون سرور، بدون حساب، بدون فراخوانی اضافهٔ AI.

  3. 03

    Shareاشتراک

    Each note is a small text file. Git, the tool programmers already use to share files, carries it to everyone.هر یادداشت یک فایل متنی کوچک است. گیت، ابزاری که برنامه‌نویس‌ها برای اشتراک فایل دارند، آن را به همه می‌رساند.

  4. 04

    Rememberبه یاد آوردن

    Before the next AI starts, it looks through the notebook and reads what teammates already did.پیش از شروع AI بعدی، دفترچه را می‌گردد و می‌خواند هم‌تیمی‌ها قبلاً چه کرده‌اند.

Words in plain Englishواژه‌ها به زبان ساده

AI helperدستیار هوش مصنوعی
A program like Claude Code, Codex, Gemini, Cursor or Copilot that writes code when you ask.برنامه‌ای مثل Claude Code، Codex، Gemini، Cursor یا Copilot که وقتی بخواهید کد می‌نویسد.
Noteیادداشت
A short summary of one work session: what was asked, what was done, which files changed.خلاصهٔ کوتاه یک جلسه کار: چه خواسته شد، چه شد، کدام فایل‌ها عوض شد.
Notebook (git repo)دفترچه (مخزن گیت)
A shared folder that remembers every change and who made it. Programmers call this “git”. GitHub and GitLab host them.پوشه‌ای مشترک که هر تغییر و تغییردهنده را به یاد می‌آورد. برنامه‌نویس‌ها به آن «گیت» می‌گویند. GitHub و GitLab میزبان آن هستند.
Hookهوک
A small automatic step: “when this happens, run that”. Here: “when the AI finishes, save a note”.یک گام خودکار کوچک: «وقتی این شد، آن را اجرا کن». اینجا: «وقتی AI تمام کرد، یادداشت را ذخیره کن».
MCPMCP
A standard plug that lets an AI app use extra tools. Here it lets the AI search the notebook by itself.یک دوشاخهٔ استاندارد که به برنامهٔ AI اجازه می‌دهد از ابزارهای اضافه استفاده کند. اینجا به AI اجازه می‌دهد خودش در دفترچه جست‌وجو کند.
Hiding secrets (“scrub”)پنهان‌کردن رازها
Passwords and keys are replaced by [REDACTED] before anything is saved.رمزها و کلیدها پیش از هر ذخیره‌ای با [REDACTED] جایگزین می‌شوند.
Summary at start (“briefing”)خلاصهٔ شروع
A few lines of recent team notes handed to the AI when it starts.چند خط از یادداشت‌های تازهٔ تیم که هنگام شروع به AI داده می‌شود.

          What it does not doکارهایی که نمی‌کند
          
  
            

          • The summary copies; it does not understand. Some notes will be messy. Read one with ganjineh show <id> before you trust it.خلاصه‌ساز فقط برمی‌دارد؛ نمی‌فهمد. بعضی یادداشت‌ها شلوغ خواهند بود. پیش از اعتماد، یکی را با ganjineh show <id> بخوانید.
          • Search matches words, not meaning. Two words that mean the same but share no letters will not match, and a Persian search will not find an English-only note.جست‌وجو واژه‌ها را تطبیق می‌دهد، نه معنی را. دو واژهٔ هم‌معنی که حرف مشترک ندارند پیدا نمی‌شوند و جست‌وجوی فارسی یادداشتِ فقط‌انگلیسی را پیدا نمی‌کند.
          • With only a few notes, it can bring up the wrong ones. Common words like “add” score high. Try ganjineh search add in a terminal above: it pulls in unrelated notes.وقتی یادداشت کم است، ممکن است یادداشت اشتباه بیاورد. واژه‌های رایجی مثل «add» امتیاز بالا می‌گیرند. در یکی از ترمینال‌های بالا ganjineh search add را امتحان کنید: یادداشت‌های نامرتبط می‌آورد.
          • Whatever a teammate types, the team can see. Hiding secrets is a best effort, not a guarantee.هر چه هم‌تیمی تایپ کند، تیم می‌تواند ببیند. پنهان‌کردن رازها تلاشِ حداکثری است، نه تضمین.
          • Not tested at all: a live AI with a real paid key, Windows, macOS, a real GitHub server (only a local test copy), big teams, Gemini’s real chat files, and how Cursor and Copilot behave.اصلاً آزموده نشده: یک AI زنده با کلید واقعیِ پولی، ویندوز، مک، سرور واقعی گیت‌هاب (فقط یک نسخهٔ آزمایشیِ محلی)، تیم‌های بزرگ، فایل‌های واقعی گفتگوی Gemini، و رفتار Cursor و Copilot.
          • It is not “for every AI”. Only the tools in the table above were checked, and only as the table says.برای «همهٔ AIها» نیست. فقط ابزارهای جدول بالا و فقط به همان اندازه که جدول می‌گوید بررسی شده‌اند.
          • No automatic test service (CI) yet: the token used to publish had no permission for it, so there is no workflow file. Run the tests yourself: PYTHONPATH=src pytest tests.هنوز سرویس خودکار تست (CI) نیست: توکنِ انتشار اجازهٔ آن را نداشت، پس فایل workflow وجود ندارد. تست‌ها را خودتان اجرا کنید: PYTHONPATH=src pytest tests.
          • A young project (v0.1.2), not on PyPI. Expect rough edges and changes before 1.0.پروژهٔ تازه (v0.1.2) و در PyPI نیست. تا پیش از ۱٫۰ انتظار لبه‌های خشن و تغییر داشته باشید.

          Where it sits among similar projectsجایگاه در میان پروژه‌های مشابه
          
  
          Other projects do similar things, and several are good: gitmem (the closest: team memory synced through git), team-memory, ai-memory, TeamBrain, Krimto, Knowit, CrewMemory, Commonwealth, claude-mem-sync, iHow Memory and mex. If one fits you better, use it. ganjineh bets on this mix: notes are saved by themselves, summaries need no AI, secrets are always hidden, notes are plain text files in git, search runs on your own computer, nothing extra to install, and Persian is handled properly. It deliberately has no meaning-based search, no web dashboard, no hosted sync and no AI-written summaries.           Installنصب
          Two steps per teammate.دو گام برای هر هم‌تیمی.
          
  
          
  
          You need Python 3.9 or newer. Nothing else to install. It is not on PyPI yet, so install it straight from GitHub (pipx is a small tool that installs Python programs):پایتون ۳٫۹ یا بالاتر لازم است و چیز دیگری نصب نمی‌شود. هنوز در PyPI نیست، پس مستقیم از گیت‌هاب نصبش کنید (pipx ابزار کوچکی برای نصب برنامه‌های پایتون است):
          
  
          pipx install git+https://github.com/mrzroot/ganjineh
ganjineh --help
          
  
          First person on the teamاولین نفر تیم: create an empty private repository (any git host) to be your team’s notebook. Then, inside your project folder:یک مخزن خصوصیِ خالی (در هر میزبان گیت) بسازد تا دفترچهٔ تیم باشد. بعد داخل پوشهٔ پروژه:
          
  
          ganjineh init --brain git@github.com:your-team/team-brain.git --area backend
git add .ganjineh.json CLAUDE.md AGENTS.md GEMINI.md .github .cursor .mcp.json .gemini .vscode .claude/settings.json
git commit -m "Add ganjineh" && git push
          
  
          Everyone elseبقیه: pull that change and run one command with your own role (add --codex to set up Codex, which is set per user):آن تغییر را بکشند و با نقش خودشان یک دستور اجرا کنند (برای Codex، که برای هر کاربر جدا تنظیم می‌شود، --codex را اضافه کنند):
          
  
          ganjineh init --area frontend
ganjineh search "refund screen"
ganjineh who server/routes/auth.py
