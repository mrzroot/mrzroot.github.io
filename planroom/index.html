02 / ASSUMPTIONS

How the forecast worksفرمول پیش‌بینی چیست؟

Subtract the current balance from the goal, floor the remainder at zero, divide by the positive monthly contribution and round up to a whole month. If the current balance already meets the goal, the estimate is zero months.موجودی فعلی را از هدف کم کنید، ماندهٔ منفی را صفر بگیرید، آن را بر واریز ماهانهٔ مثبت تقسیم کنید و به بالا گرد کنید. اگر از قبل به هدف رسیده‌اید، نتیجه صفر ماه است.

months = ceil(max(0, goal − saved) / monthly)

The example assumes constant monthly deposits and zero growth. It does not account for fees, inflation or investment returns, and it is not financial advice.نمونه واریز ثابت ماهانه و رشد صفر را فرض می‌کند. کارمزد، تورم و بازده سرمایه‌گذاری را در نظر نمی‌گیرد و توصیهٔ مالی نیست.

05 / FAQ

Privacy and scopeحریم خصوصی و دامنه

Can I connect a real portfolio here?اینجا می‌توانم حساب مالی واقعی وصل کنم؟

No. The public preview is a fictional calculator. The full project is a local portfolio demo, not a banking integration.نه. پیش‌نمایش عمومی یک محاسبه‌گر فرضی است. پروژهٔ کامل نمونه‌کار محلی است، نه اتصال بانکی.

What is kept after restarting the local app?با راه‌اندازی دوبارهٔ نسخهٔ محلی چه می‌ماند؟

The full app stores changes in PostgreSQL. docker compose down keeps the project’s database volume; the local operational guide covers a separate staging and restore workflow.نسخهٔ کامل تغییرات را در PostgreSQL نگه می‌دارد. دستور docker compose down حجم دادهٔ پایگاه را حفظ می‌کند؛ راهنمای عملیاتی مسیر جداگانهٔ آزمایشی و بازیابی را توضیح می‌دهد.

Quick startشروع سریع

The full workspace uses React, FastAPI and PostgreSQL. Start it with Docker Compose and choose Explore with sample data at localhost:8088.پنل کامل با React، FastAPI و PostgreSQL ساخته شده است. با Docker Compose راه‌اندازی کنید و در localhost:8088 گزینهٔ داده‌های نمونه را انتخاب کنید.

git clone https://github.com/mrzroot/planroom.git
cd planroom
cp .env.example .env
docker compose up --build --wait

On PowerShell, use Copy-Item .env.example .env for the copy step.در پاورشل برای مرحلهٔ کپی از Copy-Item .env.example .env استفاده کنید.
