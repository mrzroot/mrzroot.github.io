netdoctor-ir

A connectivity doctor and mirror switcher for developers in Iran.پزشک اتصال و تعویض‌کنندهٔ مخزن برای برنامه‌نویس‌های داخل ایران.

A failing pip install, npm install or docker pull in Iran could be DNS hijacking, SNI filtering or a sanctions page, and nobody knows which DNS or package mirror works today. netdoctor answers with measurements, not guesses.شکست pip install یا npm install یا docker pull در ایران می‌تواند از ربایش DNS، فیلترینگ SNI یا صفحهٔ تحریم باشد و کسی نمی‌داند امروز کدام DNS یا مخزن کار می‌کند. netdoctor با اندازه‌گیری پاسخ می‌دهد، نه حدس.

01Featuresامکانات

What it does.چه کار می‌کند.

01

Explains every failureتوضیح هر خطا

Probes 38 developer services through DNS → TCP → TLS → HTTP and gives each a verdict (OK, SLOW, SANCTIONED, FILTERED, FORBIDDEN…) with a plain-language reason.۳۸ سرویس توسعه را در مسیر DNS ← TCP ← TLS ← HTTP می‌سنجد و برای هرکدام حکمی (OK، SLOW، SANCTIONED، FILTERED و…) با توضیح ساده می‌دهد.

02

DNS ranking that mattersرتبه‌بندی واقعی DNS

Benchmarks 13 public, anti-sanction and ISP resolvers, counts hijacked answers, and with --deep checks which resolver actually unblocks Docker Hub and friends.۱۳ سرور عمومی، ضدتحریم و ISP را می‌سنجد، پاسخ‌های ربوده‌شده را می‌شمارد و با ‎--deep‎ نشان می‌دهد کدام واقعاً Docker Hub و بقیه را باز می‌کند.

03

Content-verified mirrorsمخزن‌های راستی‌آزمایی‌شده

Downloads a real artefact from each of 37 PyPI, npm, Docker, Go and Maven mirrors and checks the content, not just the status code.از هر یک از ۳۷ مخزن PyPI، npm، داکر، Go و Maven یک فایل واقعی دانلود و محتوایش را بررسی می‌کند، نه فقط کد وضعیت.

04

Switch safely, undo anytimeتعویض امن، بازگشت در هر زمان

mirrors --write updates pip.conf, .npmrc, Docker daemon.json and GOPROXY with a diff and an automatic backup; restore puts everything back.دستور ‎mirrors --write‎ فایل‌های pip.conf و ‎.npmrc‎ و daemon.json و GOPROXY را با نمایش تفاوت و پشتیبان خودکار به‌روز می‌کند و restore همه را برمی‌گرداند.

05

Reports and TUIگزارش و رابط ترمینالی

Shareable JSON or Markdown reports without your IP address, plus an optional live Textual dashboard.گزارش JSON یا مارک‌داون قابل‌اشتراک بدون نشانی IP، به‌همراه داشبورد زندهٔ اختیاری با Textual.

06

Safe and data-drivenایمن و داده‌محور

No root, no telemetry, no silent system changes. Resolvers, mirrors and sanction signatures live in YAML with a trust level per entry.بدون نیاز به root، بدون ردیابی و بدون تغییر پنهان. سرورها، مخزن‌ها و امضاهای تحریم در YAML با سطح اعتماد برای هر مورد نگهداری می‌شوند.

02Install & quick startنصب و شروع سریع

Up and running in a minute.در یک دقیقه راه بیندازید.

  1. 1Install with pipx (Python 3.10+)نصب با pipx (پایتون ۳٫۱۰ به بالا)

    pipx install git+https://github.com/mrzroot/netdoctor-ir.git

  2. 2Diagnose, then fixتشخیص، سپس اصلاح

    netdoctor scan                 # what works, what doesn't, and why
netdoctor dns --deep           # fastest resolver, and which one unblocks things
netdoctor mirrors              # which mirror is up right now
netdoctor mirrors --write      # switch pip/npm/Docker/Go (with backup)
netdoctor restore              # undo

  3. 3Share a reportاشتراک گزارش

    netdoctor report --md report.md --json report.json
  • Not on PyPI yet: install from GitHub or from the wheel attached to the v0.1.0 release.هنوز در PyPI نیست؛ از گیت‌هاب یا فایل wheel انتشار v0.1.0 نصب کنید.
