flowpilot

Lightweight, self-hosted, code-first workflow automation with first-class Telegram support.خودکارسازی گردش‌کار سبک، خودمیزبان و کدمحور با پشتیبانی کامل از تلگرام.

Platforms like n8n or Zapier are heavy to self-host or keep workflows in a database, while small cron scripts grow into unreviewable glue code. flowpilot is a tiny n8n that lives in a Git repo and runs on a $5 VPS or a Raspberry Pi.سکوهایی مثل n8n یا Zapier برای میزبانی شخصی سنگین‌اند یا گردش‌کار را در پایگاه‌داده نگه می‌دارند، و اسکریپت‌های کوچک cron به کدهای درهم و غیرقابل‌بازبینی تبدیل می‌شوند. flowpilot یک n8n کوچک است که در مخزن گیت زندگی می‌کند و روی یک VPS ارزان یا رزبری‌پای اجرا می‌شود.

01Featuresامکانات

What it does.چه کار می‌کند.

01

Code-firstکدمحور

Workflows are small YAML (or Python) files you review, diff and version in Git: no canvas, no database-only state.گردش‌کارها فایل‌های کوچک YAML (یا پایتون) هستند که در گیت بازبینی و نسخه‌بندی می‌شوند؛ نه بوم کشیدنی، نه وضعیت پنهان در پایگاه‌داده.

02

Tiny footprintردپای کوچک

One Python process with SQLite. No Redis, Postgres or Node, so it is comfortable on a Raspberry Pi or the cheapest VPS.یک فرایند پایتون با SQLite؛ بدون Redis و Postgres و Node، مناسب رزبری‌پای یا ارزان‌ترین VPS.

03

Telegram built inتلگرام داخلی

Send messages, files and photos, split long messages, call any Bot API method, and point it at a self-hosted Bot API server or proxy when api.telegram.org is unreachable.ارسال پیام، فایل و عکس، تقسیم پیام‌های بلند، فراخوانی هر متد Bot API و استفاده از سرور Bot API شخصی یا پراکسی وقتی api.telegram.org در دسترس نیست.

04

Batteries includedهمه‌چیز آماده

Cron, webhooks, file watching, RSS, HTTP, transforms, branching, retries with backoff, timeouts, persistent state, backups and e-mail.cron، وب‌هوک، پایش فایل، RSS، HTTP، تبدیل داده، شرط، تلاش دوباره با تأخیر، مهلت زمانی، وضعیت ماندگار، پشتیبان‌گیری و ایمیل.

05

Live dashboardداشبورد زنده

Live log streaming, run history, one-click runs and enable/disable, served by the same process with dark and light themes.نمایش زندهٔ لاگ، تاریخچهٔ اجرا، اجرای یک‌کلیکی و روشن/خاموش کردن، از همان فرایند و با پوستهٔ تیره و روشن.

06

Plugins in five linesافزونه در پنج خط

Write a Python function, decorate it with @step and use it in YAML. Jalali date filters are included.یک تابع پایتون بنویسید، با ‎@step‎ علامت بزنید و در YAML استفاده کنید. فیلترهای تاریخ شمسی هم آماده‌اند.

02Install & quick startنصب و شروع سریع

Up and running in a minute.در یک دقیقه راه بیندازید.

  1. 1Install from GitHubنصب از گیت‌هاب

    pipx install "git+https://github.com/mrzroot/flowpilot.git"

  2. 2Create a project and run itساخت پروژه و اجرا

    flowpilot init my-automations && cd my-automations
flowpilot validate          # static checks
flowpilot run hello         # run once
flowpilot serve             # dashboard + API + triggers on http://127.0.0.1:8080

  3. 3Connect Telegram (.env)اتصال تلگرام (‎.env‎)

    TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHAT_ID=123456789

  4. 4Or run it with Docker Composeیا با Docker Compose

    docker compose up -d   # dashboard on 127.0.0.1:8080, secrets in ./project/.env
  • Not on PyPI yet: install from GitHub or grab the wheel from the latest release.هنوز در PyPI نیست؛ از گیت‌هاب یا فایل wheel آخرین انتشار نصب کنید.
