Suggested first stepقدم اول پیشنهادی

Use a harmless local command that waits for input and compare its report with an intentionally busy command.یک دستور محلیِ بی‌خطر که منتظر ورودی می‌ماند امتحان کنید و گزارشش را با یک دستورِ عمداً پرکار مقایسه کنید.

Check process state and waiting input together. A longer timeout alone cannot identify the reason for silence.وضعیت فرایند و انتظار برای ورودی را کنار هم بررسی کن. زمان انتظار بیشتر به‌تنهایی دلیل سکوت را پیدا نمی‌کند.
