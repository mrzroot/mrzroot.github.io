Suggested first stepقدم اول پیشنهادی

In a scratch project, set the same harmless variable in two supported sources and see which value wins. Never paste real secret values into a report.در پروژهٔ آزمایشی یک متغیر بی‌خطر را در دو منبع پشتیبانی‌شده بگذارید و ببینید کدام برنده است. مقدار محرمانه را در گزارش منتشر نکنید.

Trace the effective value at the running process. Test after a restart using the corrected configuration source.مقدار مؤثر را در فرایند فعال پیدا کن. پس از اصلاح منبع تنظیم، دوباره با راه‌اندازی مجدد بررسی کن.
