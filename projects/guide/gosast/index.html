A small browser toy: tear the visible page into paper strips, rearrange them, then return to the original page.یک سرگرمی مرورگری: نمای صفحه را به تکه‌های کاغذ تبدیل کنید، جابه‌جایشان کنید و بعد به صفحهٔ اصلی برگردید.

The page is treated as paper. Preview where the tear should start and see how its origin changes the composition.صفحه را مثل کاغذ تصور کن. نقطهٔ شروع پارگی را عوض کن و شکل نهایی را ببین.

Try a response to see its effect.یک کار را انتخاب کن و اثرش را ببین.

Suggested first stepقدم اول پیشنهادی

Open a page you can safely experiment on, rearrange a few strips and use Esc to return to the original page.در صفحه‌ای بی‌خطر چند نوار را جابه‌جا کنید و با Esc به نمای اصلی برگردید.

Compare the edge and center effects on the same example. Reset between experiments to restore the original composition.اثر پارگی از حاشیه و مرکز را روی همان نمونه مقایسه کن. بین دو تجربه، نما را به حالت اصلی برگردان.
