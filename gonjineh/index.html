گنجینهgonjineh

Your team's AI agents finally share one brain.عامل‌های هوش‌مصنوعیِ تیمت بالاخره یک مغز مشترک دارند.

Alice's Claude Code builds the login button. Bob's Codex is asked for the login endpoint. Without gonjineh it invents a new one; with it, it finds Alice's note first. Hooks capture each session, a mandatory scrubber strips secrets, a plain git repo syncs the notes. No server, no accounts, no LLM calls.Claude Code آلیس دکمهٔ ورود را می‌سازد. از Codex باب اندپوینت ورود خواسته می‌شود. بدون گنجینه یکی تازه می‌سازد؛ با گنجینه اول یادداشت آلیس را پیدا می‌کند. هوک‌ها هر نشست را ثبت می‌کنند، پاک‌سازِ اجباری رمزها را می‌زداید و یک مخزن ساده‌ٔ گیت یادداشت‌ها را همگام می‌کند. بی‌سرور، بی‌حساب، بی‌فراخوانی مدل.

  3. 03

    Syncهمگام‌سازی

    One markdown file per author and session, pushed through plain git.یک فایل مارک‌داون برای هر نویسنده و نشست، با گیتِ ساده.

    Recallیادآوری

    The next agent searches first: briefing, per-prompt hint, MCP tools.عامل بعدی اول جست‌وجو می‌کند: خلاصه، راهنمای هر پرسش، ابزارهای MCP.

01

The vault labآزمایشگاه گنجینه

Two terminals. One brain.دو ترمینال. یک مغز.

Run the story, or type your own commands. Scrubbing, the note, the search and the briefing below are produced by a JS port of the real tool.داستان را اجرا کنید یا دستورهای خودتان را بنویسید. پاک‌سازی، یادداشت، جست‌وجو و خلاصهٔ زیر با پورت جاوااسکریپتِ ابزار واقعی ساخته می‌شود.

Browser simulation.شبیه‌سازی در مرورگر. The AI replies and the terminal skins are scripted; no model runs and nothing touches the network. The memory logic (scrubber, digest, search, hook gate) is the real code, ported to JavaScript and parity-checked on 77 cases.پاسخ‌های AI و ظاهر ترمینال‌ها از پیش نوشته شده؛ مدلی اجرا نمی‌شود و شبکه‌ای در کار نیست. منطق حافظه (پاک‌ساز، خلاصه‌ساز، جست‌وجو، دروازهٔ هوک) همان کد واقعی است که به جاوااسکریپت پورت شده و روی ۷۷ مورد با نسخهٔ پایتون سنجیده شده.

          What it does not doکارهایی که نمی‌کند
          
  
            
    
          • The digest extracts and quotes; it does not understand. Some notes will be noisy. Read one with gonjineh show <id> before trusting it.خلاصه‌ساز استخراج و نقل می‌کند؛ نمی‌فهمد. بعضی یادداشت‌ها شلوغ خواهند بود. پیش از اعتماد، با gonjineh show <id> یکی را بخوانید.
            • 
    
          • Search is lexical. Synonyms that share no words do not match, and a Persian query will not find an English-only note.جست‌وجو واژه‌محور است. مترادف‌هایی که واژهٔ مشترک ندارند پیدا نمی‌شوند و پرسش فارسی یادداشتِ فقط‌انگلیسی را پیدا نمی‌کند.
            • 
    
          • The gate can let noise through on a small brain. Common verbs such as “add” score highly when only a few notes exist. Try gonjineh search add in a lab terminal above: it pulls in unrelated notes.دروازه روی حافظهٔ کوچک ممکن است نویز را رد کند. وقتی فقط چند یادداشت هست، فعل‌های رایجی مثل «add» امتیاز بالا می‌گیرند. در آزمایشگاهِ بالا gonjineh search add را امتحان کنید: یادداشت‌های نامرتبط را می‌آورد.
            • 
    
          • Whatever a teammate types is visible to the team. Scrubbing is best-effort.هر چه هم‌تیمی تایپ کند برای تیم دیدنی است. پاک‌سازی تلاشِ حداکثری است، نه تضمین.
            • 
    
          • Not tested at all: live models with real keys, Windows, macOS, a real GitHub remote (a local bare repo was used), large teams, Gemini's real chat files, Cursor and Copilot behavior.اصلاً آزموده نشده: مدل زنده با کلید واقعی، ویندوز، مک، ریموت واقعی گیت‌هاب (از مخزن bare محلی استفاده شد)، تیم‌های بزرگ، فایل‌های واقعی گفتگوی Gemini، رفتار Cursor و Copilot.
            • 
    
          • No CI yet: the token used to publish the repo had no GitHub Actions scope, so there is no workflow file. Run PYTHONPATH=src pytest tests locally.هنوز CI نیست: توکنِ انتشار مخزن دسترسی GitHub Actions نداشت، پس فایل workflow وجود ندارد. تست‌ها را محلی اجرا کنید: PYTHONPATH=src pytest tests.
            • 
    
          • Young project (v0.1.0), not on PyPI. Expect rough edges and format changes before 1.0.پروژهٔ تازه (v0.1.0) و روی PyPI نیست. تا پیش از ۱٫۰ انتظار لبه‌های خشن و تغییر قالب داشته باشید.
            • 
  
          
  
          Where it sits among similar projectsجایگاه در میان پروژه‌های مشابه
          
  
          This is a crowded space and several projects are good. A search in 2026 found, among others, gitmem (the closest: git-synced team memory), team-memory, ai-memory, TeamBrain, Krimto, Knowit, CrewMemory, Commonwealth, claude-mem-sync, iHow Memory and mex. If one fits you better, use it. What gonjineh bets on is the combination: passive hook capture, an LLM-free digest, a mandatory scrubber, plain markdown in git, local BM25 search, stdlib-only Python, and Persian as a first-class case. It deliberately has no embeddings, web UI, hosted sync or LLM-written summaries. NOVELTY.md has the details and caveats.این حوزه شلوغ است و چند پروژه‌ٔ خوب دارد. جست‌وجو در ۱۴۰۵ میان بقیه، gitmem (نزدیک‌ترین: حافظهٔ تیمی همگام با گیت)، team-memory، ai-memory، TeamBrain، Krimto، Knowit، CrewMemory، Commonwealth، claude-mem-sync، iHow Memory و mex را نشان داد. اگر یکی برایتان بهتر است، همان را بردارید. شرطِ گنجینه بر ترکیب است: ثبت منفعل با هوک، خلاصه‌ساز بدون مدل، پاک‌ساز اجباری، مارک‌داونِ ساده در گیت، جست‌وجوی BM25 محلی، پایتونِ فقط‌با‌کتابخانهٔ استاندارد و فارسی به‌عنوان حالت درجه‌یک. عمداً embedding، رابط وب، همگام‌سازی میزبانی‌شده یا خلاصهٔ نوشته‌شده با مدل ندارد. جزئیات و ملاحظات در NOVELTY.md.
