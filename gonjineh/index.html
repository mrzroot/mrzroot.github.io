shared memory for your team's AI agentsحافظهٔ مشترک برای عامل‌های هوش‌مصنوعی تیم · v0.1.0

Every AI chat, filed for the whole team.هر گفتگوی هوش‌مصنوعی، بایگانی برای کل تیم.

Your frontend person and your backend person each talk to their own agent. gonjineh turns every finished session into a short, secret-scrubbed note, syncs it through a plain git repo, and lets the next agent look it up before it builds something that already exists. No server, no accounts, no LLM calls.نفرِ فرانت و نفرِ بک‌اند هرکدام با عامل خودشان حرف می‌زنند. گنجینه هر جلسهٔ تمام‌شده را به یادداشتی کوتاه و بدون رمز و کلید تبدیل می‌کند، با یک مخزن ساده‌ٔ گیت همگام می‌کند و اجازه می‌دهد عامل بعدی پیش از ساختنِ چیزی که از قبل هست، آن را پیدا کند. بدون سرور، بدون حساب کاربری، بدون فراخوانی مدل.

5Ranked notes and the gateیادداشت‌های رتبه‌بندی‌شده و دروازه

      
    
      
    BM25 with field weights, prefix expansion and Persian normalization. The gate lets a note into the prompt only if its score is at least 2.5 or two distinct query words match it, and never your own notes. Search is lexical: a Persian query will not find an English-only note.BM25 با وزن فیلدها، گسترش پیشوندی و نرمال‌سازی فارسی. دروازه فقط وقتی یادداشت را وارد پرسش می‌کند که امتیازش دست‌کم ۲٫۵ باشد یا دو واژهٔ متمایزِ پرسش در آن باشد، و هرگز یادداشت‌های خودتان را نه. جست‌وجو واژه‌محور است: پرسش فارسی یادداشتِ فقط‌انگلیسی را پیدا نمی‌کند.

      How it worksروش کار
      Five stations, no server.پنج ایستگاه، بدون سرور.
      
  
      
  
        
    
      1. 01
        Captureثبت
        Hooks fire when a Claude Code session stops, ends or compacts, and when Codex notifies. The transcript file is read; nobody writes notes by hand.وقتی جلسهٔ Claude Code متوقف می‌شود، تمام می‌شود یا فشرده می‌شود، و وقتی Codex اعلان می‌دهد، هوک اجرا می‌شود. فایل گفتگو خوانده می‌شود؛ کسی یادداشت دستی نمی‌نویسد.
        2. 
    
      2. 02
        Digestخلاصه
        Rules, not a model: what was asked, the outcome, sentences with decision, gotcha or TODO markers (English and Persian), files touched, endpoints, commands.با قاعده، نه با مدل: چه خواسته شد، نتیجه، جمله‌هایی با نشانهٔ تصمیم، نکته یا کار باقی‌مانده (فارسی و انگلیسی)، فایل‌های تغییرکرده، endpointها و دستورها.
        3. 
    
      3. 03
        Scrubپاک‌سازی
        Keys, tokens, card numbers and Iranian mobile numbers are masked in every field before the note touches disk, so they never reach git history.کلیدها، توکن‌ها، شمارهٔ کارت و موبایل ایرانی در همهٔ فیلدها پیش از رسیدن یادداشت به دیسک پوشانده می‌شوند، پس هرگز وارد تاریخچهٔ گیت نمی‌شوند.
        4. 
    
      4. 04
        Fileبایگانی
        One markdown file per session, written only by its author: entries/<project>/<area>/…md. Commit, fetch, rebase, push, with retries. Different sessions are different files, so pushes rarely conflict.برای هر جلسه یک فایل مارک‌داون که فقط نویسنده‌اش می‌نویسد: entries/<project>/<area>/…md. کامیت، fetch، rebase، push با تلاش مجدد. جلسه‌های مختلف فایل‌های مختلف‌اند، پس پوش‌ها به‌ندرت تداخل می‌کنند.
        5. 
    
      5. 05
        Recallیادآوری
        A briefing at session start, up to three matching notes per prompt (never your own), an MCP server, and a CLI: search, who, show.خلاصهٔ آغاز جلسه، حداکثر سه یادداشتِ مرتبط برای هر پرسش (هرگز از خودتان)، یک سرور MCP و یک CLI: search، who، show.
        6. 
  
      
  
      Why this shape: your team already has git access, so there is nothing new to host or pay for; plain markdown can be reviewed in a pull request; and a rule-based digest means no extra API spend and no chat text sent to a third party.چرا این شکل: تیم شما از قبل به گیت دسترسی دارد، پس چیز تازه‌ای برای میزبانی یا پرداخت نیست؛ مارک‌داونِ ساده را می‌شود در pull request بازبینی کرد؛ و خلاصه‌سازیِ قاعده‌مند یعنی هزینهٔ API اضافه و ارسال متن گفتگو به شخص ثالث ندارد.

      Privacyحریم خصوصی
      Scrubbed first. Opt out per session.اول پاک‌سازی. کنارگذاشتن برای هر جلسه.
      
  
      
    
      Always maskedهمیشه پوشانده می‌شود
      AWS, GitHub, GitLab, Slack, Stripe, Anthropic, OpenAI, Google, npm, SendGrid, Twilio and Telegram tokens; JWTs; private-key blocks; user:pass@ URLs; Bearer …; password=-style assignments; long high-entropy blobs; Luhn-valid card numbers in Latin or Persian digits. There is no switch to turn this off.توکن‌های AWS، GitHub، GitLab، Slack، Stripe، Anthropic، OpenAI، Google، npm، SendGrid، Twilio و Telegram؛ JWT؛ بلوک کلید خصوصی؛ نشانی‌های user:pass@؛ Bearer …؛ انتساب‌هایی مثل password=؛ رشته‌های بلندِ پرانتروپی؛ شمارهٔ کارتِ معتبر (لان) با رقم لاتین یا فارسی. کلید خاموش‌کردن ندارد.
      
    
      On by default, configurableپیش‌فرض روشن، قابل تنظیم
      Iranian mobile numbers ("pii": false relaxes it). Emails are not masked unless you set "mask_email": true.شمارهٔ موبایل ایرانی (با "pii": false شل می‌شود). ایمیل‌ها پوشانده نمی‌شوند مگر "mask_email": true بگذارید.
      
    
      Opt-outsکنارگذاشتن
      Write #private, gonjineh:off or #نهان in a prompt and that session is skipped entirely. .brainignore removes matching file paths. Use a private brain repo: read access to it is read access to your decisions.در یک پرسش #private، gonjineh:off یا #نهان بنویسید تا کل جلسه نادیده گرفته شود. .brainignore مسیرهای مطابق را حذف می‌کند. مخزن حافظه را خصوصی بگیرید: دسترسی به آن یعنی دسترسی به تصمیم‌های شما.
      
  
      
  
      The scrubber is pattern-based and will miss secrets with unusual shapes. Do not treat it as your only control. Try it in the demo above, then try to fool it.پاک‌ساز الگو‌محور است و رمزهای با شکل غیرمعمول را از دست می‌دهد. آن را تنها سد دفاعی خود ندانید. در نمونهٔ بالا امتحانش کنید و بعد سعی کنید فریبش بدهید.
      

      


      
  
      Limits and honestyمحدودیت‌ها و صداقت
      What it does not do.کارهایی که نمی‌کند.
      
  
        
    
      • The digest extracts and quotes; it does not understand. Some notes will be noisy. Read one with gonjineh show <id> before trusting it.خلاصه‌ساز استخراج و نقل می‌کند؛ نمی‌فهمد. بعضی یادداشت‌ها شلوغ خواهند بود. پیش از اعتماد، با gonjineh show <id> یکی را بخوانید.
        • 
    
      • Search is lexical. Synonyms that share no words do not match, and a Persian query will not find an English-only note.جست‌وجو واژه‌محور است. مترادف‌هایی که واژهٔ مشترک ندارند پیدا نمی‌شوند و پرسش فارسی یادداشتِ فقط‌انگلیسی را پیدا نمی‌کند.
        • 
    
      • The gate can let noise through on a small brain. Common verbs such as “add” score highly when only a few notes exist. Try the “noisy one” chip in the demo above: it pulls in an unrelated staging note.دروازه روی حافظهٔ کوچک ممکن است نویز را رد کند. وقتی فقط چند یادداشت هست، فعل‌های رایجی مثل «add» امتیاز بالا می‌گیرند. چیپ «نمونهٔ پرنویز» در نمونهٔ بالا را امتحان کنید: یک یادداشتِ نامرتبط دربارهٔ staging را وارد می‌کند.
        • 
    
      • Whatever a teammate types is visible to the team. Scrubbing is best-effort.هر چه هم‌تیمی تایپ کند برای تیم دیدنی است. پاک‌سازی تلاشِ حداکثری است، نه تضمین.
        • 
    
      • Not tested at all: live models with real keys, Windows, macOS, a real GitHub remote (a local bare repo was used), large teams, Gemini's real chat files, Cursor and Copilot behavior.اصلاً آزموده نشده: مدل زنده با کلید واقعی، ویندوز، مک، ریموت واقعی گیت‌هاب (از مخزن bare محلی استفاده شد)، تیم‌های بزرگ، فایل‌های واقعی گفتگوی Gemini، رفتار Cursor و Copilot.
        • 
    
      • No CI yet: the token used to publish the repo had no GitHub Actions scope, so there is no workflow file. Run PYTHONPATH=src pytest tests locally.هنوز CI نیست: توکنِ انتشار مخزن دسترسی GitHub Actions نداشت، پس فایل workflow وجود ندارد. تست‌ها را محلی اجرا کنید: PYTHONPATH=src pytest tests.
        • 
    
      • Young project (v0.1.0), not on PyPI. Expect rough edges and format changes before 1.0.پروژهٔ تازه (v0.1.0) و روی PyPI نیست. تا پیش از ۱٫۰ انتظار لبه‌های خشن و تغییر قالب داشته باشید.
        • 
  
      
  
      Where it sits among similar projectsجایگاه در میان پروژه‌های مشابه
      
  
      This is a crowded space and several projects are good. A search in 2026 found, among others, gitmem (the closest: git-synced team memory), team-memory, ai-memory, TeamBrain, Krimto, Knowit, CrewMemory, Commonwealth, claude-mem-sync, iHow Memory and mex. If one fits you better, use it. What gonjineh bets on is the combination: passive hook capture, an LLM-free digest, a mandatory scrubber, plain markdown in git, local BM25 search, stdlib-only Python, and Persian as a first-class case. It deliberately has no embeddings, web UI, hosted sync or LLM-written summaries. NOVELTY.md has the details and caveats.این حوزه شلوغ است و چند پروژه‌ٔ خوب دارد. جست‌وجو در ۱۴۰۵ میان بقیه، gitmem (نزدیک‌ترین: حافظهٔ تیمی همگام با گیت)، team-memory، ai-memory، TeamBrain، Krimto، Knowit، CrewMemory، Commonwealth، claude-mem-sync، iHow Memory و mex را نشان داد. اگر یکی برایتان بهتر است، همان را بردارید. شرطِ گنجینه بر ترکیب است: ثبت منفعل با هوک، خلاصه‌ساز بدون مدل، پاک‌ساز اجباری، مارک‌داونِ ساده در گیت، جست‌وجوی BM25 محلی، پایتونِ فقط‌با‌کتابخانهٔ استاندارد و فارسی به‌عنوان حالت درجه‌یک. عمداً embedding، رابط وب، همگام‌سازی میزبانی‌شده یا خلاصهٔ نوشته‌شده با مدل ندارد. جزئیات و ملاحظات در NOVELTY.md.
