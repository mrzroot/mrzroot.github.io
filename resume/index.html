توسعه‌دهنده‌ی نرم‌افزار با تمرکز بر backend، پایگاه داده و خودکارسازی فرایندها. تجربه‌ی عملی در تحلیل و یکپارچه‌سازی سامانه‌های اطلاعاتی اتاق بازرگانی، صنایع، معادن و کشاورزی خراسان رضوی (SQL Server و MySQL)، ساخت سامانه‌های تحت وب سازمانی (بودجه‌ریزی عملیاتی، مدیریت پیامک، مرکز داوری) و انتشار ۱۵ پروژه‌ی متن‌باز با Python، TypeScript و Go. دانشجوی کارشناسی ارشد با پایان‌نامه در حوزه‌ی یادگیری عمیق.

پروژه‌های سازمانی · اتاق بازرگانی

حکمرانی و یکپارچه‌سازی داده‌ی سامانه‌های اتاق بازرگانی خراسان رضوی

SQL Server · MySQL · Python ETL · DBML · OpenAPI 3.0 · Postman · SSO

  • تحلیل ساختار ۹ سامانه‌ی MySQL و یک پایگاه داده‌ی قدیمی SQL Server (بیش از ۱۰۰ جدول به‌همراه view، stored procedure و function).
  • تهیه‌ی شناسنامه‌ی ۲۵ سامانه، کاتالوگ داده و ماتریس حساسیت اطلاعات.
  • طراحی ETL با Python برای ساخت پایگاه داده‌ی مرجع یکپارچه (Golden Record) و داشبورد ۳۶۰ درجه‌ی اعضا.
  • مدل‌سازی ERD با DBML، طراحی API با OpenAPI 3.0 و مجموعه‌ی Postman، سند معماری هدف و پورتال یکپارچه با ورود واحد (SSO).

سامانه‌ی بودجه‌ریزی عملیاتی

Laravel · Vue 3 · TypeScript · Inertia · MySQL/MariaDB · IIS

  • سامانه‌ی تحت وب با نقش‌ها و سطوح دسترسی (مدیر سیستم، مدیر، کارشناس، مشاهده‌گر) و طراحی پایگاه داده با DBML.
  • استقرار روی Windows Server و IIS با اسکریپت نصب خودکار.

سامانه‌ی مدیریت پیامک اتاق بازرگانی خراسان رضوی

Python · Flask · Waitress · SQL Server (pyodbc) · SQLite · openpyxl

  • ورود و خروج داده با Excel، تاریخ شمسی، گزارش‌گیری مالی و پیگیری، ثبت رویدادها، پنل مدیریت و پشتیبان‌گیری.
  • اجرا به‌صورت سرویس ویندوز و پوشش با تست خودکار.

سامانه‌ی تحت وب مرکز داوری اتاق بازرگانی ایران · دفتر مشهد

Vue 3 · Vite · Pinia · Django REST Framework · Token Auth

  • ثبت و پیگیری پرونده‌ی داوری، محاسبه‌گر هزینه‌ی داوری و گردش کار کارشناسان با رابط کاربری راست‌چین؛ نسخه‌ی MVP تحویل کارفرما شد.
