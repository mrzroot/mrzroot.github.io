    Local API emulatorFlagshipv0.1.1

    MihanStack · میهن‌استک

    Problem
    Testing Iranian payment and SMS integrations needs a real merchant ID, real API credit and a sandbox that is sometimes down, and there is no easy way to reproduce a duplicate bank callback or a verify that returns the wrong amount.
    What it does
    The local development cloud for Iranian services, like LocalStack for Iranian APIs. It emulates Zarinpal, Zibal, Kavenegar and SMS.ir with their real request formats and error codes, switchable scenarios (failed, timeout, duplicate callback, wrong amount…), chaos mode, a webhook playground, record/replay with secret redaction, plugins and a Persian-friendly dashboard. Runs with npx or Docker, plus a GitHub Action for CI.
    • 4services: Zarinpal, Zibal, Kavenegar, SMS.ir
    • 10failure scenarios, per service or per request

    AI coding-agent safetyFlagshipv0.1.1

    dibs

    Problem
    AI coding agents don't see what you changed by hand between their turns, so they quietly revert your edits; and nobody tracks what is still uncommitted or unpushed.
    What it does
    Records who changed each line (you or which agent), briefs every agent on your edits at the start of its turn, blocks edits that would undo your lines, restores them, and warns about uncommitted, unpushed and remote-less work. Verified end to end with the real Claude Code, Codex, Gemini CLI and aider; also wires Cursor and Copilot.

    Release distributionFlagshipv0.1.0

    dokhaneh · دوخانه

    Problem
    When Iran's internet goes national-only or GitHub drops off a whitelist, users inside the country lose release downloads, install scripts and docs overnight, and open-source projects go dark for them.
    What it does
    Publishes every release to GitHub and to domestic hosts (ArvanCloud and Liara object storage, a Gitea mirror) in one step, with an Ed25519-signed manifest proving every mirror is identical. Generates an install.sh that tries GitHub first, falls back to domestic mirrors and checks signature and hashes. Status and verify commands, plus a GitHub Action. Not a circumvention tool: only legitimate hosts.
    • 4targets: GitHub, ArvanCloud, Liara, Gitea

    Persian text toolingFlagshipv0.1.0

    paknevis · پاک‌نویس

    Problem
    Persian text is full of small, inconsistent mistakes: missing half-spaces (ZWNJ), Arabic ي and ك, misplaced punctuation, mixed digits. Fixing them by hand is slow and error-prone.
    What it does
    A linter and auto-fixer for Persian, like Prettier/ESLint for Persian writing. It fixes only what is safe and never touches code, URLs, markup or math in Markdown, HTML and LaTeX. Runs as a Python library, CLI, pre-commit hook, GitHub Action and an in-browser playground.

    Network diagnosticsFlagshipv0.1.0

    netdoctor-ir

    Problem
    For developers in Iran, a failing pip install, npm install or docker pull could be DNS hijacking, SNI filtering or a sanctions page, and nobody knows which mirror works today.
    What it does
    A connectivity doctor and mirror switcher. It scans developer services through DNS, TCP, TLS and HTTP and explains each failure, ranks DNS resolvers, tests package mirrors by downloading real artifacts, and switches pip, npm, Docker, Go and Maven to working ones with backups and one-command restore. Report export and an optional TUI.
