01About

Practical software, written to be read.

I'm Mohammadreza Zare, known online as M-R-Z (mrzroot), a Python developer based in Mashhad, Iran. Most of my work lives where automation meets the backend: scripts that remove repetitive tasks, small services and APIs, and the tooling that keeps them running.

I care about keeping things simple. Less code, clear names, and tools that are easy to install and easy to understand. When something I build is useful to others, I publish it, whether that's a curated resource list for Persian developers, a browser extension, or a toolkit for AI coding agents.
